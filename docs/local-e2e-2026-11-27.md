# Little Graduates local end-to-end review — 27 November 2026

This review covers LittleGraduatesApp and its MontessoriTraineeTeacher backend.
Three subagents independently tested native session/materials, transport, and
embedded workspace behavior. The parent ran real PHP/MariaDB HTTP workflows and
mobile browser checks. Existing uncommitted work was preserved.

No deployment or production record changes were performed. The user chose local
tests only when access to the already-signed-in Chrome profile was unavailable.

## Verified environment

- Flutter 3.47.8 / Dart 3.13.7.
- MTT copy in `/tmp/lg-mtt-e2e`, served at `http://127.0.0.1:8765`.
- MariaDB 10.11.20, socket `/tmp/lg-mtt-db.sock`, disposable database `lg_e2e`.
- Full schema, migrations through 080, curriculum/rating seeds and fictional
  admin, teacher, basic, duty-only and class-restricted users.
- Email delivery disabled. No real parent contacts or configured external
  messaging/automation delivery endpoints were used.
- Browser rendering at 390 × 844. The embedded native bridge was simulated for
  layout checks; this is not an Android WebView/device test.

## Fixes verified

- Sign-out clears local identity immediately; account changes remove old pages.
  Late responses, including 401 responses and uploads from an older login, cannot
  invalidate the new login.
- Materials comments save locally without waiting for typing debounce. Old-day
  queued work remains preserved without appearing as today's condition. Queues,
  cached data and pending completions stay bound to their original account.
- Embedded tools reload when account or destination changes, retain the correct
  Back callback, tolerate malformed bridge messages, and display launch errors.
- Transport screens recover from failed loading, retain message drafts, discard
  stale search results, and roll back settings after a failed save. Cancelling
  one trip does not stop another trip's tracker.
- Starting/reopening a scheduled trip preserves manually added/removed children
  and stop ordering. Previously the backend rebuilt the stop list and lost edits.
- Attendance writes enforce the same class restriction as the attendance grid.
  A mixed-class batch is rejected before any rows are saved.
- Form protection rejects absent, empty, malformed and incorrect CSRF tokens.
  Inventory and student pages no longer warn on missing query/form values.
- WACRM and Automations use an explicit browser handoff instead of a blocked
  nested frame. SSO is prepared only after the user clicks, with current session,
  module and CSRF checks; the school API bearer stays inside the school app.
- Calculator/receipt links open deliberately in the browser without leaving a
  loading overlay behind. The authenticated fee guide now emits the correct
  workspace identity/ready event and remains usable inside the app.
- Staff, Expenses, My leave, Feedback and Grades no longer widen the entire
  phone page. Wide tables stay in labelled, keyboard-accessible scroll regions.
  All five were measured again at 390px; document width now stays at 390px.
