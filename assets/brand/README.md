# School brand sources

Logo: https://thelittlegraduates.in/media/logo.png (original PNG, unchanged).
Theme tokens: https://thelittlegraduates.in/ (CSS variables in the site's stylesheets).
Fonts: https://thelittlegraduates.in/media/fonts/nunito.woff2 and
https://thelittlegraduates.in/media/fonts/baloo2.woff2, converted to TTF without
changing outlines. OFL notices are stored with the fonts.

The public source logo is 100 × 100 pixels. UI uses it at 92 pixels or smaller;
platform icons only resample it onto the school cream background.
